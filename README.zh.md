# Hide Player

从Minecraft服务器中隐藏任意玩家

## 支持的版本

我出于自用而编写了它，不确定是否有其他人需要，因此当前只支持了一小部分版本。你可以在[Releases](https://github.com/KoishiMoe/HidePlayer/releases)中找到所有受支持的版本的构建。

如果你需要其他版本的支持，欢迎提出issue或pr。

## 功能

可以避免玩家出现在：
- 系统消息（如加入、离开、死亡、获得成就）
- 游戏内可见性（玩家模型、聊天、标签列表、社交界面）
- 服务器状态和查询响应
- 计分板条目

可能的应用场景：
- 服务账户/机器人管理
- 小游戏开发
- 服务器活动
- 管理员活动

## 权限

### 隐藏玩家权限
- `hideplayer.hide.*` - 从所有位置隐藏玩家
- `hideplayer.hide.systemmessage` - 隐藏系统消息
- `hideplayer.hide.ingame` - 隐藏游戏内存在和聊天消息
- `hideplayer.hide.statusandquery` - 在服务器状态/查询中隐藏
- `hideplayer.hide.scoreboard` - 隐藏计分板条目
- `hideplayer.hide.locatorbar` - 在定位条中隐藏玩家

### 管理权限
- `hideplayer.privilege.seehiddenplayer` - 查看被隐藏的玩家（所有op默认拥有）

**注意：** 玩家重新登录时会自动刷新权限，不提供手动刷新。

## 安装

1. 安装权限管理器（如LuckPerms）
2. 将此模组添加到你的服务器
3. 为需要隐藏的玩家配置权限

## 高级配置

如果你遇到任何问题，如模组冲突或严重的性能下降，你可以编辑 `config/hideplayer.mixin.conf`
并选择禁用该模组提供的任意mixin以进行测试。请注意，这会破坏部分模组功能。

## 工作原理与限制

此模组使用mixin拦截并修改Minecraft服务器的行为。它通过阻止玩家数据发送到客户端来隐藏玩家。这带来了以下好处：
- 无需客户端修改（兼容原版客户端）
- 玩家无法绕过隐藏（客户端永远不会接收到数据）
- 在某些不易修改的位置（如服务器状态和查询）上也能工作

但同时也有一些限制：
- 本模组注入的某些函数调用频率较高，可能会导致性能问题（尽管我在测试中没有注意到明显的影响）
- 它可能与某些双端模组不兼容，尤其是那些会将玩家数据发送到客户端的。这可能会导致隐藏玩家数据泄漏，甚至在客户端模组尝试访问隐藏的玩家数据时崩溃。由于有很多模组，我无法保证与所有模组的兼容性。
- 所有权限修改都需要玩家重新连接服务器才能生效。
    - 这是因为Minecraft会在玩家加入和离开时执行很多操作来通知客户端。之后，服务器只会发送玩家数据的更新。如果我们在运行时修改权限，客户端只会接收到一些更新，但没有初始数据，这会让客户端感到困惑并导致意外行为。
    - 另一个原因是，有时权限检查会带来很大开销，我们不希望每次将玩家数据发送到客户端时都进行检查。因此，我们只在玩家加入时检查权限，并缓存结果。
- 无法更精细地控制隐藏的玩家数据。比如，无法只隐藏玩家模型而保留社交屏幕、tab列表等。
  - 例如，要在tab列表中隐藏玩家，必须在服务器向客户端发送的玩家列表中完全删除该玩家。而如果玩家列表中没有该玩家，客户端会直接跳过该玩家的渲染并在日志中记录错误。因此二者只能同时隐藏。
  - 同样的情况也适用于社交屏幕和其他位置。
